# Blockchain Voting System

## Overview

A blockchain-based voting system developed using Solidity, Hardhat, React.js, and Ethers.js. The project demonstrates secure and transparent voting through Ethereum smart contracts.

## Features

* Secure voting using blockchain technology
* Smart contract-based vote management
* Prevention of duplicate voting
* Candidate vote counting
* React-based frontend interface

## Technologies Used

* Solidity
* Hardhat
* React.js
* Ethers.js
* JavaScript

## Project Structure

* **blockchain/** - Smart contracts and deployment scripts
* **client/** - React frontend application

## Installation

### Backend

```bash
cd blockchain
npm install
npx hardhat compile
npx hardhat node
npx hardhat run scripts/deploy.js --network localhost
```

### Frontend

```bash
cd client
npm install
npm start
```
